## 3. Location-Resolution & Comparison Guard Fixes

### A. Non-Silent Ludhiana District Resolution
- **Problem**: Queries mentioning Ludhiana (`ਲੁਧਿਆਣਾ` / `लुधियाना`) previously mapped directly to `entities.put("mandi", "KHANNA_PB")`, silently substituting the market without informing the user.
- **Root Cause & Domain Reality**: Ludhiana is a district in Punjab. Khanna Mandi is the registered APMC yard within Ludhiana district.
- **Resolution Implemented**:
  1. `extractEntities(text)` extracts `district: "Ludhiana"`. `mandi` is left unassigned unless the user explicitly mentions Khanna (`ਖੰਨਾ` / `खन्ना`).
  2. In `VoiceAssistantService.java`, when `district != null && mandiCode == null`:
     - Queries `mandiRepository.findByDistrictIgnoreCaseAndActiveTrue(district)`.
     - When exactly 1 mandi exists (e.g. Khanna Mandi in Ludhiana), the response explicitly states:
       > *"In Ludhiana district, the registered APMC market is Khanna Mandi. Verified Agmarknet modal rate for Wheat is ₹2320.00 per quintal (Min: ₹2275.00, Max: ₹2380.00, Reported 2026-11-07). Would you like to select Khanna Mandi or check another market?"*
       > Punjabi: *"Ludhiana ਜ਼ਿਲ੍ਹੇ ਵਿੱਚ ਰਜਿਸਟਰਡ ਏਪੀਐਮਸੀ ਮੰਡੀ 'ਖੰਨਾ ਮੰਡੀ' ਹੈ। ਖੰਨਾ ਮੰਡੀ ਵਿੱਚ ਕਣਕ ਦਾ ਪ੍ਰਮਾਣਿਤ ਮਾਡਲ ਭਾਅ ₹2320.00 ਪ੍ਰਤੀ ਕੁਇੰਟਲ ਹੈ... ਕੀ ਤੁਸੀਂ ਖੰਨਾ ਮੰਡੀ ਦੀ ਜਾਣਕਾਰੀ ਲੈਣੀ ਹੈ ਜਾਂ ਕਿਸੇ ਹੋਰ ਮੰਡੀ ਦਾ ਭਾਅ ਪੁੱਛਣਾ ਚਾਹੁੰਦੇ ਹੋ?"*
     - When multiple mandis exist in a district, all available mandis are listed and the user is prompted to choose.
     - When 0 mandis exist in a district, the user is politely prompted to choose a nearby district.

### B. Consistent Date Comparison Guard
- When comparing markets (`MANDI_COMPARISON`):
  - Requires verified price records from at least **two** mandis with identical, latest reporting dates.
  - If a state or district has fewer than two active markets on that date (e.g., Punjab currently only tracks Khanna Mandi in the database), the application explicitly declares insufficient comparative data:
    > *"Punjab में गेहूं के लिए तुलनात्मक डेटा अपर्याप्त है (वर्तमान में केवल खन्ना मंडी दर्ज है, भाव: ₹2320.00)। विश्वसनीय तुलना और मंडी सिफारिश के लिए एक ही तारीख पर कम से कम दो मंडियों के भाव दर्ज होने आवश्यक हैं।"*
  - The application strictly refuses to recommend an arbitrary market.

| :--- | :--- | :--- | :--- |

| **Gnani STT Upstream Error** | STT endpoint returns error or timeout | Backend catches `GnaniApiException` / `ResourceAccessException`, safely responds with `aiServiceStatus: "FAILED"` without process termination | **PASS** |
| **Gnani TTS Unavailable** | TTS service times out or errors | Backend returns `audioBase64: null`; frontend automatically falls back to Web Speech API labeled as `Browser Speech Synthesis (Fallback)` | **PASS** |
| **Database Interruption** | DB connection unavailable | Health endpoint reports `database: DOWN`; queries return structured fail-safe guidance | **PASS** |
